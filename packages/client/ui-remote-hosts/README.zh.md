# @deepseek-ai/dsh-client-ui-remote-hosts

[English](README.md) | 中文

## 概述

使用**主机**面板添加 SSH 开发机，并把远程会话与本地会话放在一起浏览。主机没有会话时，连接状态和错误仍然可见。你可以直接编辑、断开、重连或移除连接，无需编辑 YAML。

## 使用本包

Web bundle 加载本插件。在侧边栏顶部打开**主机**，选择**添加远程主机**，填写已有的 OpenSSH 主机别名或 `user@hostname`。你还可以填写显示名称、SSH 端口和远端 Harness 数据目录。远端需要有正在运行的 `dsh web` 进程，详见[连接前提](../../api/remote-hosts/README.zh.md#use-this-package)。

保存会写入当前 profile 并开始连接。主机行显示连接状态和错误。使用**重新连接**立即重试，或使用**断开**停止自动重试。**移除**删除已保存的连接配置，远端会话会保留。并发配置修改会被拒绝；关闭并重新打开编辑器，即可读取当前配置。

Local 会话在最前，远程主机按显示名排序，各组内的会话按最近活动排列。选择会话可读取历史或继续对话。已连接主机发生变化时，目录会自动刷新，包括首次列表请求仍未完成的情况。子代理子会话与空白导航会话不会成为列表行。

侧边栏工作区区域还显示可折叠的 **Local** 和远程主机分组。可以直接点击远程会话打开对话，当前会话会高亮显示。已保存但未连接或连接失败的主机仍显示名称与状态。**管理远程主机…**打开连接管理页面。侧边栏搜索会过滤远程会话标题，不搜索远程对话正文。


配置远程主机后，**新建会话**会打开目标选择器。选择 **Local** 或远程主机，再选择该主机的 Workspace（工作区）并点击**创建会话**。选择器默认使用当前会话所在的主机。远程会话目录刷新期间，刚选中的目录信息会让空白会话立即可用。添加 Workspace 时，填写该主机上已有目录的绝对路径。未连接的主机必须先连接才能读取 Workspace 或创建 Session；操作失败时选择器保持打开。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

- **SSH 认证使用已有的客户端配置** — 面板不保存密码或私钥。
- **没有按主机过滤或搜索** — 页面按主机分组列出全部可见会话。
